# Campfire Tales

*This is fixture data for `worldofmodcraft/site`'s build (task 009) — not a real mod.*

Campfire Tales adds a ring of storytelling NPCs around wilderness campfires. Sit down, and one of
them will spin a short original tale — no two nights alike.

## Features (v1.2.0)

- **New in 1.2.0:** a lantern-carrying storyteller variant, for camps without a lit fire.
- Twelve original short stories now, told round-robin, up from six.
- A "listen" emote that keeps you seated for the tale's duration.
- Works at any player-placed or world campfire, or the new lantern posts.

## Version history

- **1.2.0** — added the lantern-carrying variant; expanded the story pool.
- **1.1.0** — *removed*. A contributed screenshot turned out to be a re-touched Blizzard asset;
  pulled per ADR-0041 as soon as it was reported. Nothing else about that release was at fault.
- **1.0.0** — first release.
