# Lantern Quests

*This is fixture data for `worldofmodcraft/site`'s build (task 009) — not a real mod.*

A short phosphorescent quest chain through the old mine tunnels: follow a trail of glowing
lantern-moths to an abandoned prospector's camp, and decide what to do with what he left behind.

## Features

- Three-quest chain, roughly 30 minutes to complete.
- A hand-placed lantern-moth trail (purely visual, cosmetic).
- One dialogue-only choice at the end; no mechanical effect, just flavour.

## Requirements

- World of Modcraft kernel (any API version 1.x).
